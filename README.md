# Amazon ML Challenge 2026: Business Entity Resolution

A modular, scalable, competition-grade Machine Learning solution for large-scale Business Entity Resolution across noisy, heterogeneous sources.

---

## 1. Project Overview

The objective is to resolve entities across three independent sources:
- **Source 1 ($S_1$):** Deduplicated reference dataset.
- **Source 2 ($S_2$) & Source 3 ($S_3$):** Noisy secondary sources to link back to $S_1$.
- **Evaluation Metric:** Macro-averaged $F_{0.5}$ (weights precision 2× over recall).

---

## 2. Team Architecture & Responsibilities

| Role | Member | Key Modules | Focus Area |
| :--- | :--- | :--- | :--- |
| **Data & Preprocessing** | **Member 1** | `src/normalization.py`<br>`src/preprocessing.py` | Unicode accent stripping, legal suffix standardization, address abbreviations, whitespace/null cleaning. |
| **Blocking & Candidates** | **Member 2** | `src/blocking.py` | Strict country partitioning, multi-pass union blocking (first word, 3-char/4-char prefixes, street number/PIN). |
| **Features & Modeling** | **Member 3** | `src/features.py`<br>`src/model.py` | 14 pairwise features (Jaccard, character n-gram cosine, number match, missingness flags), LightGBM classification. |
| **Integration & Leader** | **Member 4** | `src/evaluation.py`<br>`src/pipeline.py`<br>`run_pipeline.py` | Official Macro $F_{0.5}$ evaluation, threshold optimization, output generation, official submission validation. |

│   ├── test_normalization.py    # Unit tests for text cleaning
│   ├── test_blocking.py         # Recall validation on real ground truth
│   └── test_model.py            # Unit tests for features and LightGBM probabilities

│   ├── data_audit.md            # Comprehensive Phase 1 dataset audit report

## 4. How to Run the Project

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run Module Unit Tests
```bash
# Test Normalization (Member 1)
python tests/test_normalization.py

# Test Blocker & Recall (Member 2)
python tests/test_blocking.py

# Test Features & ML Classifier (Member 3)
python tests/test_model.py
```

### 3. Run the Master End-to-End Pipeline
```bash
python run_pipeline.py
```

### 4. Validate Submission Format
```bash
python utils/validate_submission.py \
    --matching outputs/matching_results.tsv \
    --candidate outputs/candidate_pairs.tsv \
    --test-dir data/dataset/test
```
